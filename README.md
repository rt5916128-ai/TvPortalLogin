# Вход в сеть (TV Portal Login)

Приложение для Android TV, которое помогает подключиться к интернету провайдера,
требующего авторизацию через страницу в браузере (логин + пароль).

## Что умеет
- При запуске само проверяет интернет и, если нужен вход, открывает страницу авторизации провайдера.
- Управление пультом: **виртуальный курсор** (стрелки — двигать, OK — нажать). У края экрана страница прокручивается.
  Кнопка «Меню» на пульте или «Курсор: ВКЛ/ВЫКЛ» переключает режим курсора.
- **Мои данные…** — сохранить логин и пароль, чтобы не набирать их пультом каждый раз.
  Они подставляются в форму автоматически (или кнопкой «Вставить логин/пароль»).
- **Адрес…** — открыть любой адрес вручную и сохранить его как страницу входа (например, `http://192.168.1.1`).
- После входа приложение само видит, что интернет появился, и пишет «✓ Интернет подключён».
- Может открываться из системного уведомления «Войдите в сеть».
- Принимает самоподписанные сертификаты страницы входа (с подтверждением).

## Настройка под Nobel (login3.net, «wlfl»)
1. Откройте приложение → **Мои данные…**
2. Выберите **Voucher (код)** и введите код, или **Member** и введите логин и пароль.
3. Нажмите **Сохранить и войти**. Приложение само выберет нужную вкладку на странице,
   впишет данные и нажмёт **Login**. Дальше это будет происходить автоматически при каждом запуске.

Если вход не прошёл (например, неверный код), приложение не будет повторять попытку чаще раза в 20 секунд.

## Как собрать APK

### Вариант 1 — без установки программ (GitHub)
1. Создайте пустой репозиторий на github.com и загрузите в него содержимое этой папки (кнопка «Add file → Upload files»).
2. Откройте вкладку **Actions** — сборка запустится сама (файл `.github/workflows/build.yml`).
3. Через 3–5 минут откройте завершённую сборку и скачайте артефакт **TvPortalLogin-apk** (внутри `app-debug.apk`).

### Вариант 2 — Android Studio
1. Установите Android Studio, выберите **Open** и укажите эту папку.
2. Дождитесь синхронизации Gradle, затем **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
3. Файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Как установить на телевизор
- **Флешка:** скопируйте APK на флешку, на ТВ откройте любой файловый менеджер (например, File Commander)
  и запустите файл. Разрешите установку из неизвестных источников, когда ТВ попросит.
- **Send Files to TV:** приложение на телефоне и ТВ, отправка файла по Wi‑Fi в той же сети.
- **ADB:** `adb connect <IP-телевизора>` и `adb install app-debug.apk`.

После установки приложение «Вход в сеть» появится в списке приложений ТВ.
